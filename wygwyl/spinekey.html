WHERE NEW RECORDS ARE WRITTEN

The spine databases are corpus-side (not published — they carry local paths). New records of this kind belong beside them, in the same schema, so the excavators keep working: total-cinome.json for the album, per-poem json for a single poem's run. The published twins of this grammar live here as the atlas's data ledgers.
