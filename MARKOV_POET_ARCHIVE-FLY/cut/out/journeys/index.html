THE JOURNEYS

No picture is shown twice — not in a film, not across the set. 124 usable pictures in, 80 out, each used exactly once. And no KIND of picture appears twice inside a film: every shot is a different sort of image. The order is a path that minimises the cost of each individual cut, so every join is matched, while the path can never come back to anything. Pace is off each track's own loudness curve — loud cuts fast, quiet holds.
