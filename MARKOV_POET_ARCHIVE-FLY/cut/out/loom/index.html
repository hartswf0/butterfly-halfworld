THE LOOM — a weave that moves

Run beflix-E once a frame and the obvious thing happens: every cell re-picks its element and the picture boils. It reads as noise, because nothing on screen lasts long enough to be a thing.

So the elements are agents. Each one is a specific cut-out — this person, that window — and it keeps that identity for the whole film. What changes is where it stands. Every frame the ink field is recomputed and each agent seeks a cell that wants ink, preferring the one it already holds. When the picture changes they do not blink out and reappear. They migrate.

  • Hysteresis — an agent keeps its cell while that cell still wants ink, so a standing figure stays standing instead of flickering.
  • Assignment — the homeless claim the nearest unclaimed hungry cell, so the crowd flows rather than teleports.
  • Damping — positions ease toward their target. That is what makes it motion and not a cut.
  • A reserve — an agent with nowhere to go drifts and waits at the margin rather than dying. Without it the crowd fell from 929 to 333 over two hundred frames, which is a population collapse dressed up as an effect.

THE MORPH IS WHAT PERSISTENCE IS FOR

Given two sources the field crossfades while the agents do not change. The same fourteen hundred cut-outs that built a city walk into the shape of a face. That is a claim about the archive, not an effect: the same material makes both pictures, and you can watch it change its mind.
