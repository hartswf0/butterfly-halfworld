WHAT EACH FORMAT IS
EDL
.edl
CMX3600 edit decision list — what every NLE will open. Event, source clip, source in/out, record in/out, and the shot’s name in a comment line.
OTIO
.otio
OpenTimelineIO — the same cut as a timeline object, for anything that speaks it (Resolve, Flame, Nuke Studio, otiotool).
JSON
.json
The event list this archive actually cuts from: patch, source path, source in-point, record in-point, duration, stanza, label, screen text, and the poem line where there is one. THE SCRIPTS are rendered from these.
CUE
.cue
Cue sheet for the 60bpm deck.
