# Layers, clips, and mosaics

    cut/out/op16/index.html  →  AUTHOR › The stack

## a layer you cannot see is not a layer

Every row in the stack now carries a **thumbnail of itself** — that patch alone,
baked and drawn small — so the list is a set of pictures rather than a set of
names. Tap a row and it selects; its own controls open underneath, and only the
ones it can answer to:

    ■ element   x · y · size · floor · and the mosaic controls
    ▶ clip      x · y · size · floor · frame
    ◈ world     which world, at what second, how many parts
    ▤ ground    nothing — it is what the frame already was

`▲▼` restack, `ON/OFF` withholds without deleting, `✕` removes. Every one of
them re-bakes the frame from what is left.

## a clip is a patch that knows its frame

`Stream the shot in` makes N nodes and commits you to a cut. Often what you want
is the shot **in this frame** — a photograph the size of the field, under
everything else, that you can move, resize and step through a frame at a time.

`Bring the shot in as a layer` does that: the shot's id and an index into the
packed sheet. Laid across many frames it will be the same patch with a different
`k`, which is why bringing a clip in is not an import — it is **one layer that
happens to advance**.

## a mosaic is one patch that repeats

Fifty tiles as fifty layers would be fifty things to manage and one thing to
think about. So the repetition lives **on the patch**:

    mode     grid · row · scatter
    repeat   1–144
    gap      the pitch
    jitter   how far each tile wanders
    vary     how much each tile's size varies

Change the count and the whole field re-lays. It stays one row in the stack, one
thing to switch off, one thing to restack.

## verified — a painting in four moves

    1  stamp one window at 34 cells        1,944 ink
    2  tap the layer → grid                a 3×3 field, one patch
    3  scatter · 42                        forty-two windows across the frame
    4  bring the shot in as a layer        it lands on top and hides them
    5  press ▼ once                        the shot goes under and the mosaic
                                           reads over it — the poet showing
                                           through the gaps

That last step is the argument for the whole model. The mosaic was not remade;
the stack was reordered and the frame rebuilt. In OP-14 step 4 would have been
the end of the picture.
